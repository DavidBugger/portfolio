# Job Qualification Response

## Question

Can you describe your experience modernizing an older, outdated website, including the specific technical and performance improvements you made?

## Answer

Yes. I have experience modernizing older or underperforming websites by improving both the visible user experience and the technical foundation behind the site. My approach usually starts with an audit of the existing website: page structure, mobile responsiveness, navigation, content clarity, loading speed, SEO metadata, heading hierarchy, image handling, broken user flows, and conversion paths.

One example is Mabiz Global, where I worked on the frontend and backend architecture for the company's website. The goal was to give the business a more professional, search-friendly, and maintainable online presence. I improved the structure of the site, organized the service content more clearly, added SEO-focused page structure, improved responsiveness across devices, and made the website easier to maintain and expand. The result was a cleaner business website that better communicated the company's tax, audit, and business services while giving users a smoother experience.

Another example is the Oya Riyders website and mobility platform. I worked on the public-facing website and platform using Next.js, Tailwind CSS, Supabase, Paystack, and Google Maps. The modernization work included improving the responsive layout, creating clearer user journeys, adding better page structure for search visibility, supporting faster page experiences, and integrating important business flows such as ride/service discovery, payments, and location-aware functionality. I also added SEO improvements so the site could better support organic discovery for mobility-related services.

From a technical perspective, the improvements I focus on include semantic HTML, proper title and description metadata, clean heading structure, optimized images, mobile-first layouts, faster frontend rendering, cleaner navigation, better call-to-action placement, and backend structures that make future content updates easier. Where needed, I also improve database queries, caching, API performance, and deployment setup so the website is not just better-looking, but faster and more reliable.

The outcome of this kind of modernization is usually a website that loads faster, works better on mobile, communicates the business more clearly, is easier for search engines to understand, and gives visitors a clearer path to take action.
